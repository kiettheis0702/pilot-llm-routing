## Evidence and meaning

`public-verification.json` records a real anonymous GraphQL readback on
2026-10-30 at 13:08:24 UTC: **1,128 finished runs, all expected configs and 13,314
metrics** match the local frozen payload. The HTTP session had `trust_env=False`,
no authentication and no Authorization/Cookie request headers. All 12 pages
were read; the server reported `readOnly=true` for the anonymous viewer.
Config float values allow one ULP for serialization; other scalar config
values/types are exact. Metrics use relative and absolute tolerance 1e-12.

A separate signed-out browser showed the project, Public visibility and 1,128
runs while showing Log in/Sign up links. This supplements the exhaustive API
readback; we do not claim to have manually opened every run in the browser.
The signed-out artifact page also displayed version v0, 19 files and 7.2 MB.

`experiment-map.csv` was generated by joining the original frozen map to the
verified run IDs. Source hashes, script paths and source IDs are unchanged;
only public URL and status columns were populated. It contains 1,098 historical
deployment conditions, 18 synthetic policy records and 12 cost-accounting
records. These are historical imports with one aggregate history row per run,
not newly executed LLM calls or full epoch trajectories.

The original research/course packages and PPTX files remain unchanged. Their
pre-publication flags and blank links are historical. The old presentation
publication reader only accepts a legacy wandb.ai/browser-proof schema; this
Forge-domain anonymous-API manifest is deliberately a separate evidence format.
Use this map for Claude's new slides/poster rather than relabeling old evidence.

## Release checks and limits

The Git history scan examined 528 reachable blobs (including Office XML) and
found no matching credential patterns or raw dataset/model-weight paths. This
is a scoped automated check, not a claim that every possible secret was ruled out.
Raw data, credentials, local caches and checkpoints stay outside Git.

The source report hashes are historical snapshots. Later upload/runtime fixes
do not silently change those frozen experiment claims. The complete GPU grid
has not been reproduced afresh on a clean machine; exact 11-model paper
equivalence remains unresolved. Moodle submission has not been performed.

W&B currently displays an Academic trial ending 29 November 2026. No paid
upgrade/payment method was enabled. Continued access after the trial has not
been verified; resolve free/Academic account eligibility and recheck the public
link before the 5 December poster deadline. GitHub holds an independent copy
of the research evidence.
